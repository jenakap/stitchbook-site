# Stitchbook landing page

A single static page: `index.html` (plus `images/`), served by GitHub Pages from `main`. This repo is
public, so nothing private goes in it.

To update it, edit `index.html` and push `main`; Pages publishes within a minute or two. Open
`index.html` in a browser first to check it, narrow and wide.

* **What's new:** add a block at the top of `.updates-list` for each release, newest first.
* **Keep these true:** the supported file formats (hero and FAQ), what leaves the Mac (beta box and FAQ),
  and the install/price wording.
* **Screenshots:** about 1760 px wide and under about 500 KB each; use designs you have the right to show.

The wording comes from the app's changelog and a short checklist kept with the app's source.
